03

Variables, types and input

Every C object has a type that determines supported operations, representation and alignment. Common scalar types include char, short, int, long, long long, floating-point types, and _Bool (or bool from stdbool.h).

Sizes are platform-dependent. sizeof(char) is always 1 C byte; use stdint.h types such as uint32_t when a fixed-width type exists and the representation matters. Use size_t for byte sizes and indexes.

Formatted I/O%d int · %u unsigned · %zu size_t · %f double in printf · %p void pointer
Input safetyCheck scanf returns. Prefer fgets + parsing for robust input handling.
● ● ●   types.c
#include <stdio.h>
#include <stdint.h>
#include <stddef.h>
#include <stdbool.h>

int main(void) {
    int temperature = -5;
    uint32_t flags = 0xA5u;
    size_t count = 3;
    bool ready = true;
    printf("temp=%d flags=0x%X count=%zu ready=%d\n",
           temperature, (unsigned)flags, count, ready);
    printf("sizeof(int)=%zu sizeof(pointer)=%zu\n",
           sizeof(int), sizeof(void *));
    return 0;
}
↳ Example terminal output
temp=-5 flags=0xA5 count=3 ready=1
sizeof(int)=4 sizeof(pointer)=8

Why it matters: Example sizes are for a common 64-bit Linux ABI; do not hard-code them.

● ● ●   input.c
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

int main(void) {
    char line[64];
    printf("Enter a number: ");
    if (!fgets(line, sizeof line, stdin)) return 1;
    char *end;
    errno = 0;
    long n = strtol(line, &end, 10);
    if (errno || end == line || (*end != '\n' && *end != '\0')) {
        fputs("Invalid integer\n", stderr);
        return 1;
    }
    printf("Twice = %ld\n", n * 2);  /* Choose a safe range in real code. */
    return 0;
}
↳ Example terminal output
Enter a number: 21
Twice = 42

Why it matters: Production input parsing must also guard multiplication overflow and enforce an allowed range.

04

Operators and expressions

Operators work on values: arithmetic + - * / %, comparisons == != < > <= >=, logic && || !, assignment = +=, conditional ?:, and bitwise operators covered later. Integer division truncates toward zero; 5 / 2 is 2.

Distinguish = (assignment) from == (comparison). Be careful with signed/unsigned conversions, overflow and expression order. && and || short-circuit.

● ● ●   operators.c
#include <stdio.h>
int main(void) {
    int a = 7, b = 3;
    printf("%d %d %d\n", a / b, a % b, a > b);
    printf("%d\n", (b != 0) && (a / b > 1));
    printf("%s\n", (a % 2) ? "odd" : "even");
    return 0;
}
↳ Example terminal output
2 1 1
1
odd
05

Decisions and loops

Conditionals select behavior, loops repeat behavior. Practice if/else, switch, for, while, do/while, break and continue. A switch usually needs break to prevent intentional fall-through.

Linux programs repeatedly process events, network packets or file chunks—loops are the basis of all three.

● ● ●   control.c
#include <stdio.h>
int main(void) {
    int mode = 2;
    switch (mode) {
        case 1: puts("READ"); break;
        case 2: puts("WRITE"); break;
        default: puts("UNKNOWN");
    }
    for (int i = 1; i <= 5; ++i) {
        if (i == 3) continue;
        printf("%d ", i);
    }
    putchar('\n');
    return 0;
}
↳ Example terminal output
WRITE
1 2 4 5
06

Functions and recursion

Functions divide a program into reusable operations. Define the return type, name, and parameter types. C passes arguments by value—to modify an object owned by a caller, pass its address. A recursive function must have a terminating case.

Linux APIs also follow clear function signatures: ssize_t read(int fd, void *buf, size_t count).

main()caller
→ parameters
add(int a, int b)new call frame
→ return value
main()continues
● ● ●   functions.c
#include <stdio.h>

int add(int a, int b) { return a + b; }
void swap(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}
int factorial(int n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}
int main(void) {
    int x = 4, y = 9;
    swap(&x, &y);
    printf("x=%d y=%d sum=%d fact=%d\n",
           x, y, add(x, y), factorial(5));
    return 0;
}
↳ Example terminal output
x=9 y=4 sum=13 fact=120

Why it matters: Recursion consumes stack space and may overflow for large n; this factorial also overflows int for sufficiently large inputs.

Scope asks where a name is visible; storage duration asks how long the object exists. Automatic locals normally live while their block executes; static locals persist across calls; file-scope globals have static storage duration. extern declares an object/function defined elsewhere.

08

Arrays and strings

Arrays store elements contiguously. C performs no automatic bounds checks. When an array is used in many expressions it converts to a pointer to its first element, but sizeof array works only while the array type is still known.

A C string is an array of char terminated by \0. strlen counts characters before the terminator; sizeof gives the array’s total size when applied to an array. Use bounded input and output.

index 010
index 120
index 230
index 340

Four adjacent int objects; &a[i+1] - &a[i] == 1. Actual byte stride is sizeof(int).

● ● ●   arrays.c
#include <stdio.h>
#include <string.h>
int main(void) {
    int numbers[] = {10, 20, 30, 40};
    size_t n = sizeof numbers / sizeof numbers[0];
    int sum = 0;
    for (size_t i = 0; i < n; ++i) sum += numbers[i];
    char msg[16] = "Linux";
    printf("count=%zu sum=%d\n", n, sum);
    printf("strlen=%zu sizeof=%zu\n", strlen(msg), sizeof msg);
    return 0;
}
↳ Example terminal output
count=4 sum=100
strlen=5 sizeof=16
● ● ●   safe_string.c
#include <stdio.h>
#include <string.h>
int main(void) {
    char name[12];
    printf("Name: ");
    if (!fgets(name, sizeof name, stdin)) return 1;
    name[strcspn(name, "\n")] = '\0';
    printf("Hello, %s\n", name);
    return 0;
}
↳ Example terminal output
Name: Ada
Hello, Ada

Why it matters: If the input exceeds the buffer, fgets leaves remaining input unread; real interactive programs can detect and drain it.

09

Pointers: the essential model

A pointer stores an address of an object or function. &x gets an address, *p dereferences a valid pointer, and NULL represents a null pointer. Pointer types determine alignment requirements and how pointer arithmetic advances.

Never dereference an uninitialized, null, stale, or out-of-bounds pointer. Linux syscall interfaces take pointers to user buffers: read(fd, buffer, count) is a classic example.

address: 0x...A0 (example)int x = 42value: 42
← points to ←
address: 0x...B0 (example)int *p = &xvalue: &x

Addresses are illustrative. p stores an address; *p accesses the object there.

Linux connection

Pointer correctness underpins ioctl arguments, socket buffers, mmap, shared memory mappings and driver/user memory copies.

● ● ●   pointer_basics.c
#include <stdio.h>
int main(void) {
    int x = 42;
    int *p = &x;
    printf("before: x=%d *p=%d\n", x, *p);
    *p = 99;
    printf("after: x=%d *p=%d\n", x, *p);
    printf("address=%p\n", (void *)p);
    return 0;
}
↳ Example terminal output
before: x=42 *p=42

● ● ●   pointer_arithmetic.c
#include <stdio.h>
#include <stddef.h>
int main(void) {
    int a[] = {4, 8, 12};
    int *p = a;
    printf("%d %d %d\n", *p, *(p + 1), p[2]);
    ptrdiff_t distance = &a[2] - &a[0];
    printf("element distance=%td\n", distance);
    return 0;
}
↳ Example terminal output

Why it matters: Pointer subtraction is defined for pointers into the same array (including one past the end).

10

Double pointers and pointer arrays

Read declarations carefully: int **pp is a pointer to a pointer; char *argv[] is an array of pointers to char; int (*p)[4] points to an array of four ints.

Use a double pointer when a function must change the caller’s pointer, e.g. allocate a buffer or update a linked-list head.

● ● ●   double_pointer.c
#include <stdio.h>
#include <stdlib.h>

int allocate_number(int **out) {
    if (!out) return -1;
    *out = malloc(sizeof **out);
    if (!*out) return -1;
    **out = 123;
    return 0;
}
int main(void) {
    int *p = NULL;
    if (allocate_number(&p) != 0) return 1;
    printf("value=%d\n", *p);
    free(p);
    return 0;
}
↳ Example terminal output
value=123

Dynamic memory and ownership

malloc allocates uninitialized bytes; calloc allocates and zero-initializes bytes; realloc can resize an allocation; free releases it. Always check allocation results, avoid integer overflow while computing sizes, and arrange exactly one logical owner for each allocation.

Linux connection

Allocate packet buffers and userspace I/O buffers with checked sizes, and design a clear cleanup path for every error case.

● ● ●   heap.c
#include <stdio.h>
#include <stdlib.h>
int main(void) {
    size_t n = 4;
    int *values = calloc(n, sizeof *values);
    if (!values) { perror("calloc"); return 1; }
    for (size_t i = 0; i < n; ++i) values[i] = (int)(i * 10);
    for (size_t i = 0; i < n; ++i) printf("%d ", values[i]);
    putchar('\n');
    free(values);
    values = NULL;
    return 0;
}

Structures, unions, enums and layout

struct groups related fields. union overlays members in shared storage and needs careful tracking of the active representation. enum names integer constants. An ABI-sensitive structure can contain compiler-inserted padding; do not serialize it by dumping raw memory unless the external format explicitly requires that layout.

typedef creates a type alias—not a new distinct type. offsetof helps inspect layout. Bit-fields are compiler/ABI-dependent and should not be assumed to match wire formats or hardware registers.

char tag1 byte
paddingimplementation-dependent
int countoften 4 bytes
short modeoften 2 bytes
tail paddingimplementation-dependent

Illustrative common ABI: actual offsets and sizes must be queried with offsetof and sizeof.

Linux connection

Kernel APIs are full of structures and function pointers. Understand padding, pointer ownership, p->field and exact-width integer types first.

● ● ●   structs.c
#include <stdio.h>
#include <stddef.h>
#include <stdint.h>

enum State { STOPPED, RUNNING };
struct Packet {
    uint8_t type;
    uint32_t length;
    enum State state;
};
int main(void) {
    struct Packet p = { .type = 2, .length = 128, .state = RUNNING };
    printf("type=%u len=%u state=%d\n",
           (unsigned)p.type, (unsigned)p.length, p.state);
    printf("offset(length)=%zu size=%zu\n",
           offsetof(struct Packet, length), sizeof p);
    return 0;
}
↳ Example terminal output
type=2 len=128 state=1
offset(length)=4 size=12

Why it matters: Offset and size are sample values for a common ABI; verify on your machine.

13

Bitwise operations and byte order

Bitwise & | ^ ~ << >> work on individual bits. Set a flag with OR, clear it with AND plus complement, toggle with XOR, and test with AND. Favor unsigned types for shifts and masks, and avoid shifting by a negative amount or an amount at least the type width.

Endian describes byte order in multi-byte values: little endian stores the least significant byte first; big endian stores it last. Use serialization APIs or explicit byte extraction for portable binary protocols.

Device register fields, protocol headers, ioctl options and network payloads often require bit masks and explicit byte order handling.

● ● ●   flags.c
#include <stdio.h>
#include <stdint.h>
#define FLAG_READ  (1u << 0)
#define FLAG_WRITE (1u << 1)
#define FLAG_SYNC  (1u << 2)
int main(void) {
    uint32_t flags = 0;
    flags |= FLAG_READ | FLAG_SYNC;     /* set bits */
    printf("set=0x%X\n", (unsigned)flags);
    flags &= ~FLAG_SYNC;              /* clear bit */
    printf("clear=0x%X read=%d\n",
           (unsigned)flags, (flags & FLAG_READ) != 0);
    return 0;
}
↳ Example terminal output
set=0x5
clear=0x1 read=1

File handling with stdio

Buffered stdio offers fopen, fgets, fprintf, fread, fwrite and fclose using FILE *. Check errors and close files. Text and binary file handling may differ by platform, even though Linux generally treats file bytes uniformly.

● ● ●   file_stdio.c
#include <stdio.h>
int main(void) {
    FILE *f = fopen("notes.txt", "w");
    if (!f) { perror("fopen write"); return 1; }
    if (fprintf(f, "Linux\nC programming\n") < 0) {
        perror("fprintf"); fclose(f); return 1;
    }
    if (fclose(f) != 0) { perror("fclose"); return 1; }
    f = fopen("notes.txt", "r");
    if (!f) { perror("fopen read"); return 1; }
    char line[80];
    while (fgets(line, sizeof line, f)) printf("%s", line);
    int bad = ferror(f);
    if (fclose(f) != 0 || bad) return 1;
    return 0;
}

File descriptors and POSIX I/O

Linux system programs often bypass buffered stdio and operate on integer file descriptors: open, read, write, close. read may return fewer bytes than requested, 0 for EOF, or -1 for error. write may also write fewer bytes. Proper code uses loops and handles EINTR.

stdin, stdout and stderr commonly correspond to descriptors 0, 1 and 2. lseek changes a seekable descriptor's offset. dup2 supports redirection.

Device nodes under /dev are also opened as descriptors and accessed with read, write and sometimes ioctl.

● ● ●   posix_io.c — Linux / POSIX
#define _POSIX_C_SOURCE 200809L
#include <fcntl.h>
#include <unistd.h>
#include <errno.h>
#include <stdio.h>

int main(void) {
    int fd = open("demo.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
    if (fd == -1) { perror("open"); return 1; }
    const char text[] = "hello via write\n";
    size_t left = sizeof text - 1;
    const char *p = text;
    while (left) {
        ssize_t n = write(fd, p, left);
        if (n < 0 && errno == EINTR) continue;
        if (n <= 0) { perror("write"); close(fd); return 1; }
        left -= (size_t)n;
        p += n;
    }
    if (close(fd) == -1) { perror("close"); return 1; }
    puts("written");
    return 0;
}

Many POSIX functions report failure with -1 and set errno. Examine errno only after detecting a failure; another operation may change it. perror and strerror help explain failures. In reliable systems code, use a single cleanup path when acquiring multiple resources.

int main(void) {

#include <stdio.h>
#include <stdlib.h>
int compare_ints(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y); /* avoids subtraction overflow */
}
int main(void) {
    int a[] = {8, 2, 11, 1};
    qsort(a, 4, sizeof a[0], compare_ints);

    putchar('\n');
    return 0;
}

Linked lists and data structures

Pointer-driven data structures are practical training for systems engineering. A linked list stores data and a pointer to the next node; insertion is cheap once the insertion position is known, but searching is linear. In real kernels, Linux uses intrusive linked-list helpers with different ownership patterns.

● ● ●   linked_list.c
#include <stdio.h>
#include <stdlib.h>
struct Node { int value; struct Node *next; };
int main(void) {
    struct Node *head = malloc(sizeof *head);
    if (!head) return 1;
    head->value = 7;
    head->next = malloc(sizeof *head);
    if (!head->next) { free(head); return 1; }
    head->next->value = 12;
    head->next->next = NULL;

    for (struct Node *p = head; p; p = p->next)
        printf("%d -> ", p->value);
    puts("NULL");
    while (head) {
        struct Node *next = head->next;
        free(head);
        head = next;
    }
    return 0;
}

Undefined behavior includes out-of-bounds access, signed integer overflow, use-after-free, invalid pointer dereference and many data races. Such bugs may appear to work in debug builds then fail in production. Use compiler warnings, debugger watchpoints, sanitizer builds and focused experiments.

gdb lets you set breakpoints, inspect values, step through instructions and show call stacks. strace shows system calls, while ltrace (when available) shows dynamic library calls.

Your bridge to Linux system programming

Now combine C into your first OS programs. fork starts a child process; pipe creates a unidirectional byte stream; read/write transport bytes; waitpid reaps the child. Later study execve, mmap, poll/epoll, POSIX shared memory, semaphores, threads and sockets.

Do not confuse pointer values in separate processes with shared memory. After fork, processes generally have independent copy-on-write virtual address spaces.

● ● ●   pipe_fork.c — Linux / POSIX
#define _POSIX_C_SOURCE 200809L
#include <unistd.h>
#include <sys/wait.h>
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int fd[2];
    if (pipe(fd) == -1) { perror("pipe"); return 1; }
    pid_t pid = fork();
    if (pid == -1) { perror("fork"); close(fd[0]); close(fd[1]); return 1; }
    if (pid == 0) {
        close(fd[1]);
        char b[64];
        ssize_t n = read(fd[0], b, sizeof b - 1);
        if (n <= 0) _exit(1);
        b[n] = '\0';
        printf("child got: %s\n", b);
        fflush(stdout);
        close(fd[0]);
        _exit(0);
    }
    close(fd[0]);
    const char message[] = "Hello from parent";
    if (write(fd[1], message, sizeof message - 1) != (ssize_t)(sizeof message - 1)) {
        perror("write");
    }
    close(fd[1]);
    int status;
    if (waitpid(pid, &status, 0) == -1) { perror("waitpid"); return 1; }
    printf("child exited=%d\n", WIFEXITED(status) ? WEXITSTATUS(status) : -1);
    return 0;
}
↳ Example terminal output
child got: Hello from parent
child exited=0

Why it matters: This example sends a short message that fits within the pipe’s atomic write limit; robust general-purpose code loops for partial writes, retries EINTR and handles short reads.
