# The Learning Curve

A study library for networking, programming and Linux infrastructure. Build foundations here, then apply them to trading systems and latency diagnosis in the companion HFT library.

## Start studying

- Double-click **Start Library.command** for the complete reading experience, including embedded PDFs. Keep its Terminal window open while reading.
- [Open the searchable reader](index.html)
- [Follow the study path](00_study_guides/04_study_path.md)
- [Track practical skills and evidence](00_study_guides/05_study_tracker.md)
- [QuickRef cheat sheets for revision](00_study_guides/07_quickref_review_links.md)
- [Open HFT Engineering](../HFT_Docs/index.html)

## Subject map

| Folder | Purpose |
| --- | --- |
| 00_study_guides | Starting routes, reference guides and progress tracking |
| 01_networking | CCNA, CCNP, classes and network design |
| 02_cpp | C++ concepts and existing exercises |
| 03_python | Study routes, lessons and exercises |
| 04_ansible | Configuration management |
| 05_docker | Container foundations |
| 06_linux_performance | Linux performance references |
| 07_packet_analysis | Wireshark and packet inspection |
| 08_english | Communication and vocabulary |
| 09_embedded_linux_c | Embedded Linux and C material; currently personal notes |
| 10_go | Reserved for future Go material |

Personal-note directories, archives and build artifacts remain on disk but are excluded from the reader. Empty subjects do not appear as finished courses.

## Maintaining the library

After editing sources or adding PDFs, double-click **Start Library.command** again. It prepares its private Python environment when needed, refreshes the index and opens the local reader. See [library maintenance](00_study_guides/06_library_maintenance.md) for naming and publishing rules.
