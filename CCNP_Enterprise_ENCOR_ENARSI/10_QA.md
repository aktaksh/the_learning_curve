# Knowledge Q&A — ENCOR and ENARSI

Answer aloud before revealing the text after the dash. These are original study questions.

## Architecture and virtualization

1. **RIB versus FIB?** — RIB holds selected routes; FIB contains forwarding entries derived for fast lookup.
2. **What is an adjacency?** — Resolved next-hop rewrite and egress information used by forwarding.
3. **CAM versus TCAM?** — CAM is commonly used for exact MAC lookup; TCAM supports masked/prefix/policy matches.
4. **Two-tier versus three-tier?** — Two-tier collapses distribution/core; three-tier separates them.
5. **What does an FHRP provide?** — A shared virtual default gateway with active/master failover.
6. **What does SSO aim to preserve?** — Control-plane state through supervisor failover where supported.
7. **Policing versus shaping?** — Police limits by drop/remark; shape buffers and spaces traffic.
8. **What is a QoS trust boundary?** — Point where endpoint markings are accepted or rewritten.
9. **Why can a VRF reuse another VRF's subnet?** — Each VRF has a separate routing table.
10. **Does GRE encrypt?** — No; add suitable security such as IPsec when required.
11. **LISP versus VXLAN role?** — LISP commonly maps endpoint identity/location; VXLAN encapsulates overlay traffic.
12. **Why test tunnel MTU?** — Extra headers reduce payload capacity and can black-hole large packets.

## Infrastructure and assurance

13. **What makes an MST region consistent?** — Matching name, revision and VLAN-to-instance mapping.
14. **LACP passive/passive?** — No side initiates; the bundle will not form.
15. **One flow on a four-link port-channel?** — Usually hashes to one member.
16. **Does OSPF point-to-point elect DR?** — No.
17. **Normal DROTHER-to-DROTHER state?** — 2-Way on a broadcast network can be normal.
18. **BGP `network` statement prerequisite?** — Exact prefix/mask present in local RIB.
19. **What can leave BGP Established with no route?** — No source route, export/import filter, address-family activation or invalid next hop.
20. **What is RPF?** — Multicast source check against the unicast route toward that source.
21. **IGMPv3 advantage for SSM?** — Receiver can specify source and group.
22. **NTP versus PTP?** — Both synchronise time; PTP with suitable hardware can reach tighter accuracy.
23. **What can SPAN miss?** — Mirrored packets during oversubscription and original hardware timing fidelity.
24. **NetFlow record/monitor/exporter?** — Fields; collection/cache attachment; export to collector.
25. **IP SLA plus track?** — Probe state can drive route/FHRP decisions.
26. **NETCONF versus RESTCONF?** — Structured network APIs with different transport/interface models; both can expose YANG data.

## Security and automation

27. **Why can CoPP break OSPF?** — It can drop packets destined for the router's CPU.
28. **802.1X three roles?** — Supplicant, authenticator, authentication server.
29. **Why is MAB weaker?** — MAC identity can be spoofed; apply restricted fallback policy.
30. **What does MACsec protect?** — Supported Ethernet link traffic.
31. **What does EEM do?** — Executes configured actions in response to events.
32. **JSON boolean spelling?** — `true`/`false`, lowercase.
33. **HTTP 401 versus 403?** — Authentication missing/invalid versus authenticated but forbidden.
34. **What is YANG?** — Data modelling language for network configuration and state.

## Advanced routing

35. **What wins first, longest prefix or AD?** — Longest prefix.
36. **EIGRP feasible condition?** — Neighbour RD strictly less than local FD (`RD < FD`).
37. **Feasible successor?** — Loop-free prequalified backup satisfying FC.
38. **Stuck in active implies?** — DUAL query/reply process did not finish in time; investigate reachability/scale/resources.
39. **Why use an EIGRP stub?** — Limit query scope at an edge.
40. **OSPF ABR versus ASBR?** — ABR connects areas; ASBR injects external routes.
41. **NSSA purpose?** — Area with reduced external LSAs that can inject its own external routes as type 7.
42. **E1 versus E2 external metric?** — E1 accounts for internal path cost to ASBR; E2 is chiefly external metric.
43. **Why tag redistributed routes?** — Match and block feedback into the source domain.
44. **Can a summary hide an outage?** — Yes; it can remain advertised while a specific component route disappears.
45. **BGP weight versus local preference?** — Weight is local to one Cisco router; local pref propagates in the AS and affects outbound choice.
46. **Why does iBGP need full mesh or RR?** — iBGP-learned paths are not re-advertised to other iBGP peers by default.
47. **Lower or higher MED preferred when compared?** — Lower, subject to comparison rules.
48. **What does PBR override?** — Normal destination-only routing for matched packets on the ingress policy interface.
49. **What does BFD accelerate?** — Failure detection, not necessarily full application recovery.

## VPN and services

50. **MPLS label switching encrypts?** — No.
51. **RD versus RT?** — RD makes VPN prefixes unique; RT controls import/export membership.
52. **What is NHRP's job in DMVPN?** — Map tunnel addresses to underlay NBMA addresses.
53. **Why might DMVPN small ping work but application fail?** — PMTU/MSS or selective policy/loss.
54. **Strict uRPF risk?** — Drops legitimate packets when return route uses a different interface.
55. **Does DHCPv6 normally provide default gateway?** — No; IPv6 router advertisements provide it.
56. **Why correlate syslog time?** — Wrong clocks can invert apparent event order.
57. **Why can NetFlow collector be empty during traffic?** — Wrong monitor direction, exporter route/source, record or collector parsing.
58. **SNMPv3 advantage?** — Authentication and privacy compared with v2c community model.
59. **What proves microburst loss?** — Rising queue/NIC drop counters and timed capture/telemetry, not low average utilisation.
60. **What proves failover readiness?** — Reachability, loss duration and latency/jitter of the backup path under load.
